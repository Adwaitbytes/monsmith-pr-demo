# Monsmith pull request review, demo

A small staking vault used to show the [Monsmith GitHub App](https://www.monsmith.com/github) reviewing real pull requests.

Open the pull requests tab to see what it does: one comment kept up to date on every push, findings on their lines in "Files changed", a count of what each push fixed, and an onchain attestation on Monad when the pull request merges.

The bugs in the pull requests are deliberate.
